# Исключения

### Содержание проекта:
В пакете `src/` находятся классы `Product` и `Category`, для которых определены следующие свойства:
1. Для класса `Product`
- название (name),
- описание (description),
- цена (price),
- количество в наличии (quantity).
2. Для класса `Category` 
- название (name),
- описание (description),
- список товаров категории (products).
Для класса `Product` созданы два класса наследников: «Смартфон» (Smartphone) и «Трава газонная» (LawnGrass).
Класс `Smartphone` расширен атрибутами: производительность (efficiency), модель (model), 
объем встроенной памяти (memory), цвет (color).
Класс `LawnGrass` расширен атрибутами: страна-производитель (country), срок прорастания 
(germination_period), цвет (color).
Для класса `Category` также добавлены два атрибута класса: количество категорий и количество товаров.
Для обоих классов определены магические методы `__str__`, `__add__`, `__iter__` и `__next__`.
Для всех классов реализованы ограничения сложения с помощью функций `issubclass()` и `isinstance()`.
3. Создан базовый абстрактный класс с именем `BaseProduct`, который является родительским для классов продуктов.
- Классы «Смартфон» и «Трава газонная» наследуются только от класса `Product`.
- Выделена общая для каждого продукта функциональность и описана в абстрактном классе.
4. Реализован класс-миксин, который при создании объекта распечатывает в консоль информацию о том, от какого класса 
и с какими параметрами был создан объект. Миксин добавлен в цепочку наследования класса `Product`.
 
Также в модуле `main.py` реализована дополнительная функция `load_categories_from_json`, которая подгружает
данные по категориям и товарам, а также создает объекты классов из JSON-файла в папке `data/`. 

### В домашней работе 17.1:
1. При создании товара с нулевым количеством вызывается исключение ValueError, которое выдает сообщение: "Товар 
с нулевым количеством не может быть добавлен". При этом выполнение программы прерывается.
2. В классе Category реализован новый метод `middle_price`, который подсчитывает средний ценник всех товаров. 
С помощью исключений обрабатывается случай, когда в категории нет товаров и сумма всех товаров будет делиться на ноль.  
При этом возвращается ноль.
3. Дополнительное задание: создан пользовательский класс исключения `ZeroQuantityError`, который отвечает за 
обработку событий, когда в «Категорию» или «Заказ» добавляется товар с нулевым количеством. Исключение вызывается 
и выводит соответствующее сообщение.
